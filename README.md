## Branch Naming Guidelines

All team members must strictly follow this branch naming convention:

### Format
`Feature/RoleInitials-LastName-short-description`

### Role Initials
* **SM:** Scrum Master
* **UIX:** UI/UX Designer
* **DEV:** Developer
* **DBA:** Database Administrator
* **TST:** Tester

### Examples
* **Scrum Master:** `Feature/SM-Nieva-readme-guidelines`
* **UI/UX Designer:** `Feature/UIX-Nieva-auth-layouts`
* **Developer:** `Feature/DEV-[LastName]-auth-api`
* **DB Admin:** `Feature/DBA-[LastName]-db-schema`
* **Tester:** `Feature/TST-[LastName]-test-plan`

> **Rule:** Direct commits to `main` are prohibited. Create a feature branch matching the rule above, push your code, and open a Pull Request linking to your issue (e.g., `Closes #11`)[cite: 3, 4].
