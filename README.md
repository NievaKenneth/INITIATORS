## Branch Naming Guidelines

All team members must follow this strict branch naming convention before making any changes:

### Format
`Feature/LastName-short-description`

### Examples
* **Scrum Master / UI:** `Feature/Nieva-agent-setup`
* **Developer:** `Feature/[LastName]-auth-api`
* **DB Admin:** `Feature/[LastName]-db-schema`
* **Tester:** `Feature/[LastName]-test-plan`

> **Rule:** Never commit directly to `main`. Always create your branch using the format above, push your code, and open a Pull Request linking to your issue (e.g., `Closes #11`).
